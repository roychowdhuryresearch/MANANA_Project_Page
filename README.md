# MANANA project page

Project website for **Teaching LLMs to Recommend and Defer in Underrepresented Epilepsy Care** (NeurIPS 2026).

[Website](https://roychowdhuryresearch.github.io/MANANA_Project_Page/) · [Paper](https://arxiv.org/abs/2606.31036) · [Code](https://github.com/roychowdhuryresearch/Manana)

Publication layout and styling adapted from [PANINI-DR](https://github.com/roychowdhuryresearch/PANINI-DR_Project_Page).

Static HTML, CSS, and JavaScript. GitHub Pages serves the root of `main`.
To preview locally: `python -m http.server 8000`.

Tables 1–3 reproduce the final paper's main results, BPA weighting ablation, and selective prediction results. Public paper figures are in `assets/`.
