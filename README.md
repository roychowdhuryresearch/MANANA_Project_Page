# MANANA project page

Project page for **Teaching LLMs to Recommend and Defer in Underrepresented Epilepsy Care** (NeurIPS 2026).

[Website](https://roychowdhuryresearch.github.io/MANANA_Project_Page/) · [Paper](https://arxiv.org/abs/2606.31036) · [Code](https://github.com/roychowdhuryresearch/Manana)

Static HTML, CSS, and JavaScript with no build step. GitHub Pages serves the root of `main`.
Preview locally with `python -m http.server 8000`.

All numbers on the page come from the camera-ready paper. The learned artifacts are copied verbatim from
[`docs/artifacts/learned_artifacts.md`](https://github.com/roychowdhuryresearch/Manana/blob/main/docs/artifacts/learned_artifacts.md).
Figures in `assets/` are rendered from the paper's figure PDFs.

Layout inspired by the [PANINI-DR project page](https://github.com/roychowdhuryresearch/PANINI-DR_Project_Page).
